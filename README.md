## About

I’m **Vijay Shikhare**, a full-stack developer and product-minded engineer
based in Maharashtra, India. I build responsive web applications, useful
interfaces, and backend foundations that are designed to be understood,
extended, and shipped with confidence.

My work spans the full product loop: shaping an idea, turning it into a
focused user flow, building the frontend, designing the API, connecting the
data layer, and refining the details that make a product feel finished.
