## How I work

1. **Clarify the outcome** — understand the user, the constraint, and what
   success needs to look like.
2. **Build in visible milestones** — keep scope clear and feedback useful from
   the first interface to the final release.
3. **Keep the system understandable** — prefer accessible UI, explicit APIs,
   sensible data models, and code that another engineer can extend.
4. **Ship with care** — test the important paths, communicate trade-offs, and
   leave the product in a better state than I found it.
