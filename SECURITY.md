# Security Policy

## Repository scope

This is a public profile repository. It does not contain application
credentials, production infrastructure, or private deployment configuration.

## Reporting a concern

If you find exposed personal information, a compromised workflow, a malicious
change, or another security concern, please contact Vijay privately through
[email](mailto:vijayshikhareteam@gmail.com) rather than opening a public issue.

Please include the affected file or URL, a short description of the concern,
and any steps needed to reproduce it. Do not include secrets in the report.

## Responsible disclosure

Please allow reasonable time for investigation and remediation before making
security details public.
