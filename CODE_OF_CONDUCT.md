# Code of Conduct

## Our Pledge

This profile repository is maintained as a professional public presence. Participation in any discussion, issue, or contribution should stay respectful, constructive, and focused on quality.

## Standards

Expected behavior includes:

- Clear and respectful communication
- Professional feedback
- Good-faith collaboration
- Respect for different viewpoints and experiences

Unacceptable behavior includes:

- Harassment or personal attacks
- Abusive, discriminatory, or inflammatory language
- Spam or unrelated promotional content
- Deliberate disruption of discussion

## Enforcement

If a problem arises, the repository owner may remove content or decline collaboration that does not align with this standard.

## Scope

This code of conduct applies to interactions related to this repository and any profile-linked public collaboration.
